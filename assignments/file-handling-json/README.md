# 📘 Atividade: File Handling and JSON Persistence

## 🎯 Objetivo

Pratique a leitura e escrita de arquivos em Python, aprendendo a armazenar e recuperar dados em formato JSON para criar um pequeno sistema de persistência.

## 📝 Tarefas

### 🛠️ Criar a Estrutura de Dados

#### Descrição
Defina uma estrutura simples para armazenar itens, como uma lista de tarefas ou uma coleção de produtos.

#### Requisitos
O programa concluído deve:

- Usar uma estrutura de dados em Python, como lista ou dicionário.
- Representar pelo menos 3 itens com informações relevantes.
- Preparar os dados para serem salvos em um arquivo JSON.

### 🛠️ Salvar Dados em Arquivo JSON

#### Descrição
Escreva os dados em um arquivo JSON para que permaneçam disponíveis depois de encerrar o programa.

#### Requisitos
O programa concluído deve:

- Criar um arquivo chamado `data.json`.
- Salvar os dados em formato JSON usando Python.
- Garantir que o arquivo seja gerado corretamente no diretório do projeto.
- Verificar o conteúdo final do arquivo para confirmar a estrutura correta.

### 🛠️ Ler e Atualizar Informações

#### Descrição
Implemente a lógica para carregar os dados do arquivo, adicionar ou remover itens e salvar novamente.

#### Requisitos
O programa concluído deve:

- Ler o conteúdo do arquivo JSON com Python.
- Adicionar ou remover um item da lista.
- Salvar a lista atualizada no mesmo arquivo.
- Exibir o resultado final de forma clara para o usuário.
